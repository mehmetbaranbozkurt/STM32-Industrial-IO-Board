# STM32 Industrial I/O Board

An industrial STM32-based control and I/O board designed for learning and portfolio purposes.

## Features

- 24 V DC input
- 5 V and 3.3 V power rails
- STM32 microcontroller
- 24 V digital inputs
- MOSFET digital outputs
- 0-10 V analog input
- CAN Bus communication
- RS485 communication
- SWD programming interface
- Input protection
- Status LEDs
